# Compound Interest Calculation

This project calculates compound interest using JavaScript with static (predefined) values.

## Formula Used

A = P(1 + (r / n))^(n * t)

Where:
- P = principal amount
- r = annual rate of interest (as a decimal)
- n = number of times interest is compounded per year
- t = time in years
- A = final amount

## Files

- `index.html` - Main HTML file
- `style.css` - Styling for the page
- `script.js` - JavaScript code that performs the calculation
- `README.md` - Project documentation

## How to Test

1. Open `index.html` in a web browser.
2. Open the browser's developer tools (Console tab).
3. The result will be printed in the console.

## Static Values Used

- Principal (P) = 25600
- Rate (r) = 0.25 (25% per year)
- Compounded per year (n) = 1
- Time (t) = 3 years
